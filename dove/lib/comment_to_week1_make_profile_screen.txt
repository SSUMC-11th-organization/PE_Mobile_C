방법 1. 섹션마다 위젯 클래스를 만든다 (추천)

섹션별로 StatelessWidget을 만들고, Column의 children에는 그 이름만 나열합니다.

body: Column(
  children: [
    const SizedBox(height: 24),
    const _ProfileHeader(),   // 이미지, 닉네임, 소개글, 수정 버튼
    const _StatsSection(),    // 통계 카드 3개
    const _GenreSection(),    // 선호하는 장르
  ],
),
class _ProfileHeader extends StatelessWidget {
  const _ProfileHeader();

  @override
  Widget build(BuildContext context) {
    return Column(
      children: [
        // 이미지, 닉네임, 소개글, 버튼
      ],
    );
  }
}
클래스 이름은 자유롭게 지어도 되고, 앞에 _를 붙이면 이 파일 안에서만 쓰는 비공개 위젯이 됩니다.
섹션별로 코드가 나뉘어서 build가 짧아집니다. asset_demo.dart의 _SectionTitle, _FitBox가 이미 이 방식이에요.
파일이 길어지면 lib/widgets/ 폴더로 옮겨 다른 파일에서 import해도 됩니다.
